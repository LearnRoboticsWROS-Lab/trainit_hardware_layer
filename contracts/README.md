# The contracts

A **contract** is the ROS interface a hardware *role* exposes — topics, services,
frames, units — stated once and independently of what implements it.

An **adapter** realises one contract on one backend. A **profile** describes one
specific piece of hardware in the contract's terms.

```
        contract (this folder)          "a gripper serves eef/<id>/actuators/<a>/set_engaged"
              ▲         ▲
    adapter ──┘         └── adapter      mock · isaac · real · (gazebo)
              ▲
         profile                         "the SoftGripper suction cup, 40 mm, 0.4 kg"
```

## The rule that makes it worth doing

**Application code names the contract, never the backend.** A behaviour tree says
`CloseGripper eef="main"`; TMR sends the device's standard command (a SetBool on
`eef/main/actuators/vacuum/set_engaged`, relative to the robot's namespace) and never knows
whether that reaches Isaac, a vendor controller, or a mock. Swapping the backend is a launch
argument, not a code change. (A legacy project calls `/suction/on` the same way.)

The pattern predates this package. `isaac_suction_bridge.py` already says it:

> *Exposes the SAME ROS2 contract as the real fairino_gripper suction node, so MoveIt /
> behavior trees / your code are IDENTICAL between Isaac and real hardware.*

What this package adds is a **place** for it, and the contract written down instead of
living in docstrings.

## Two kinds of adapter

They are not interchangeable and must not be filed together:

| | runs where | shipped how |
|---|---|---|
| **ROS-side bridge** | a normal ROS node | `ros2 run`, listed in `deployment.bridges` |
| **Simulator-side script** | inside Isaac, as an OmniGraph Script Node in the USD | `trainit_isaac_kit --into <cell>_isaac` |

A simulator-side script cannot be a ROS node: Isaac Sim 5.1 runs Python 3.11 while ROS 2
Humble's `rclpy` is built for 3.10, so `import rclpy` fails inside Isaac. That is why the
Isaac side talks to ROS through the ros2_bridge OmniGraph nodes and a plain topic.

## Backend matrix

| Role | mock | isaac | real | gazebo |
|---|---|---|---|---|
| robot | `ros2_control` mock components | `topic_based_ros2_control` | `fairino_bridge` | — |
| gripper (canonical, ADR-0022) | `mock_eef_adapter` *(here)* | `isaac_eef_adapter` *(here)* + the stage-side script | `ros2_control` via the vendor bring-up, or none | `ros2_control` |
| gripper (legacy) | generated by TSA | `<cell>_isaac/scripts/isaac_suction_bridge.py` | `fairino_gripper` | — |
| camera | `mock_camera` *(here)* | Isaac ROS2 Camera Helper, configured — no node | `realsense2_camera` in the Jetson container | — |

Vendor adapters (`fairino_*`) stay in their own repositories: they are the vendor's, not
TrainIt's. This layer *declares* them in a profile, it does not contain them.
